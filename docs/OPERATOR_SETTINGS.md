# 操作台参数设置

启动 `scripts/run_operator.sh`，在连接设备、启动相机之前点击右上角 **⚙ 设置**。
设置窗口使用分组标签页；主操作台继续保留相机预览、操作流程和 Episode 控件。

## 保存和生效

1. 修改所需参数，或在 O6 页编辑动作、选择张开和闭合动作。
2. 点击 **保存参数**。格式、范围或动作引用不合法时，页面显示具体错误并保留输入。
3. 关闭并重新启动程序，然后按原流程连接设备。新参数在此次启动时加载。

配置保存到 `config/roarm_cr5_teleop.json`，保存前的完整文件备份到同目录
`roarm_cr5_teleop.json.bak`。备份保留最近一次保存前的版本，已从 Git 跟踪中排除。
保存通过现有配置存储器原子替换文件；如果文件在编辑期间被外部程序改动，
本次保存报错，需要重新打开设置页。取消或关闭有修改的设置页时，可以选择继续编辑或放弃。

设置采用独立配置副本，保存不会改写当前运行对象或当前数采配置快照。
保存后主页面提示重启，并禁用新的控制器连接和相机启动入口。
设备已连接、相机已启动、命令执行中或 Episode 尚未处理时，设置入口不可用。

## 参数范围与单位

| 页面 | 可设置内容 | 生效范围 |
| --- | --- | --- |
| 机械臂 | ServoJ v/a/j、单帧跳变、主臂速度、连续超限帧数、跟踪误差停止阈值 | 当前关节跟随流程 |
| 机械臂 | XYZ 相对范围、TCP 线速度、姿态范围、角速度、主臂位置和姿态跳变 | 已有笛卡尔跟随模式 |
| GELLO | 关节倍率、反馈频率和超时、稳定时间、XYZ/姿态倍率、串口及资源路径 | 沿用当前控制模式和标定 |
| O6 动作 | 动作库、J7 开合动作选择、六电机速度和力矩、死区、超时、串口、Modbus 地址 | O6 配置和跟随映射 |
| 数采与相机 | 默认任务、数据目录、标识前缀、FPS、质量阈值、相机序列号、Base ROI、worker 解释器 | 新的数据集与相机实例 |
| 控制器连接 | IP/主机名、命令端口、Servo 端口、机器人编号 | 下次手动连接 |

ServoJ v/a/j 保留本地 SDK 的原始数值语义，不将其标为未经确认的物理单位。
角度保护值以 rad 或 rad/s 显示；数采跟踪误差质量阈值使用度，二者用途不同。
XYZ 范围是相对跟随起点的 ±mm 范围，不是绝对工作空间边界。
本次没有新增 J1–J6 绝对软限位，也没有改变控制模式、标定、硬件默认速度或现有保护阈值。
当前新操作台的控制器生命周期固定使用 ServoJ，因此本页不提供 MoveJ 模式切换。

数采质量超限仍标记 `needs_review`，独立运动保护仍负责停止运动。
三路 RGB 输出维持 224×224，未开放会改变数据格式的尺寸编辑。

## O6 动作库

六列顺序与现有驱动一致：拇指弯曲、拇指侧摆、食指、中指、无名指、小指。
位置、速度和力矩均为 0–255 原始整数，不表示角度或牛顿米。

- 在表格中修改动作名称和六个位置值；**新增动作**复制选中行，未选中时复制原张开动作。
- 可删除未使用的动作。为兼容旧操作入口，保留“张开手”和“抓取”这两个名称，可修改其值。
- 选择 **J7 张开动作 / J7 闭合动作**，然后保存整个参数页。
- 关节模式使用所选动作名称，J7 在现有 0.5 阈值切换。
- 更换选择或编辑所选动作时，同时更新连续跟随使用的 `o6.open/closed` 端点。
  未编辑的历史端点保留原值。
- 保存后的动作库整体加载，已删除的默认动作不会在重启时重新出现。

动作编辑页只管理配置。实际跟随仍通过原有控制链执行，并需要完成真机验收。

## 代码边界与离线验证

- `gello_cr.app.settings`：参数字段定义、输入校验、独立配置副本、冲突检测与保存。
- `gello_cr.ui.settings_dialog`：参数表单和动作库交互，通过注入的设置对象保存。
- `gello_cr.ui.session` / `__main__`：注入设置工厂，界面不直接读取运行设备。
- `teleop_runtime.py`：沿用配置存储器；加载动作库时保留删除结果，关节循环读取开合选择。

`tests/v2/test_operator_settings.py` 覆盖配置重载、未编辑参数保留、备份、非法输入、
文件冲突、写盘失败、取消编辑、动作选择、主页面重启提示、设备和 Episode 状态门控，
并使用假 GELLO / 机械臂 / O6 验证保存的动作确实由跟随循环发送。
Qt 界面验收使用 offscreen 窗口；这些结果不包含真实硬件动作验收。
