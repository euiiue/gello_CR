# 机械臂回初始位 HOME

传统数采工作台（`TEST_INEXBOT.py`）的三个 HOME 按钮和 F11 使用同一入口。
机械臂连接后即可点击，不依赖 GELLO、O6、相机、Episode 保存状态或当前跟随／回放状态。
重复点击会提示已有 HOME 请求，不重复发送目标。

点击后的顺序：

1. 取消跟随、预设、回放和轨迹录制，立即请求机械臂停止；确认运动线程退出。
2. 结束当前 LeRobot Episode 采样，保留已有帧，HOME 回位不混入训练动作。
3. 确认停止，必要时调用已有使能流程；控制柜拒绝使能时显示错误。
4. 按配置中的 HOME 关节目标和预设速度执行 MoveJ；检查到位及停止后的关节误差。
5. 保持停止、已使能状态，不自动恢复跟随。被打断的 Episode 可保存为失败或丢弃。

本入口只让机械臂回 HOME，不驱动 GELLO 或让 O6 回预设手势。
未保存 HOME 时明确报错，不猜测零位。软件停止／急停可取消正在等待或运动中的 HOME。
控制器 SDK 调用和运动线程退出仍需要时间；确认停止失败时不会继续发回位目标。

使用原有 `presets.HOME.robot_joints_deg`（SDK 角度单位）和 `preset` 速度参数；没有改动本机保存的目标或速度。
离线测试覆盖单独连接机械臂、抢占回放、使能、使能中取消、重复请求、录制停止失败、工作流收敛和待保存数据保留；未执行真机回位。
